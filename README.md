# Ayanami Voice

Клиентский модуль для воспроизведения входящего Steam Voice в **48 кГц**:
настраиваемая громкость, выравнивание голосов и дополнительное шумоподавление.

`Windows x86` · `CS 1.6` · `v9` · `Официальный выпуск проекта`

[**Скачать v9**](https://github.com/cuteporn/ayanami-voice/releases/download/v9/Ayanami-Voice-v9.zip) · [Релизы](https://github.com/cuteporn/ayanami-voice/releases) · [Установка](#установка) · [Команды](#команды)

Я — [Agnessa / cuteporn](https://github.com/cuteporn), автор Ayanami Voice.
Имена `Voice48.asi`, `Voice48.ini` и команды `Agn_` я сохранила для совместимости.

## Возможности

- Декодирование и отдельный вывод входящей речи в 48 кГц.
- Громкость до **4000% — ×40** с ограничением громких пиков.
- Выравнивание громкости отдельных говорящих.
- RNNoise для шумных микрофонов других игроков — включается по желанию.
- Настройка через консоль без перезапуска игры.
- Возврат к штатному голосу одной командой: `Agn_Enable 0`.

Модуль не изменяет твой микрофон, сетевой битрейт и остальные звуки игры.
48 кГц — частота декодирования и воспроизведения, а не обещание передачи
голоса в новом качестве. Потерянные детали записи и сетевые пакеты не восстанавливаются.

> Я проверила модуль; ещё 20+ игроков тоже использовали его — блокировок VAC
> мы не наблюдали. Это наш опыт, а не одобрение Valve и не гарантия отсутствия
> блокировок в будущем. Обхода античита в модуле нет.

## Установка

1. Скачай архив и **закрой CS**.
2. Если Voice48 уже установлен, сохрани копии `Voice48.asi` и `Voice48.ini`.
3. Из папки `Модуль/Half-Life` скопируй `Voice48.asi` в папку игры **рядом с `hl.exe`**.
4. При первой установке скопируй туда же `Voice48.ini`.
   **При обновлении оставь свой INI**, чтобы сохранить настройки.
5. Запусти CS и введи в консоль:

```cfg
Agn_Status
```

Ожидается `Voice48 v9` и `active=1`. Когда услышишь других игроков,
выполни команду ещё раз: рост `packets` подтверждает обработку голоса.

Правильное расположение:

```text
Half-Life/
├── hl.exe
├── Voice48.asi
├── Voice48.ini
└── cstrike/
```

Пример: `D:\Steam\steamapps\common\Half-Life\`.
Не клади модуль в `cstrike`. `hw.dll`, `steam_api.dll` и `client.dll` заменять не нужно.
Отдельный ASI-загрузчик в архив не входит: нужен клиент, который загружает
совместимые ASI через Miles. Если модуль не загружается, не подменяй системные DLL.

## Быстрая настройка

```cfg
Agn_Enable 1
Agn_Volume 10
Agn_Denoise 0
Agn_Normalize 1
Agn_MaxGain 6
Agn_Target -22
Agn_Buffer 30
Agn_Save
```

`Agn_Volume 10` = 100%, `20` = 200%, `400` = 4000%.
Если тихо, начни с `12.5` — это 125%. Максимум громкости не означает максимум качества.
Для шумного голоса попробуй `Agn_Denoise 1`; если меняется тембр или пропадают
тихие слова, верни `0`.

## Команды

Все настройки применяются сразу. Вызов без значения показывает текущее значение.
Для сохранения после изменений используй `Agn_Save`.

| Команда | Диапазон | Назначение |
|---|---|---|
| `Agn_Enable` | `0 / 1` | Штатный голос / Voice48. |
| `Agn_Volume` | `0–400` | Громкость: `10` = 100%, `400` = 4000%. |
| `Agn_Denoise` | `0 / 1` | Шумоподавление RNNoise. |
| `Agn_Normalize` | `0 / 1` | Выравнивание громкости говорящих. |
| `Agn_MaxGain` | `0–12` | Предел автоусиления, дБ. |
| `Agn_Target` | `−30…−18` | Целевая громкость нормализации, дБFS. |
| `Agn_Buffer` | `0–100` | Стартовый буфер, мс. Больше — выше задержка. |
| `Agn_MuteUnfocused` | `0 / 1` | Слышать / заглушать голоса при Alt-Tab. |
| `Agn_Status` | — | Версия, состояние, пакеты и ошибки. |
| `Agn_Save` | — | Сохранить настройки в `Voice48.ini`. |
| `Agn_Reset` | — | Вернуть стандартные настройки. |
| `Agn_Help` | — | Показать список команд. |

## Если не работает

Открой `Voice48.log` рядом с `hl.exe`.

| Симптом | Что проверить |
|---|---|
| Нет команд и нового блока `experimental v9` в логе | Правильная папка, замена ASI, перезапуск и загрузка модуля клиентом. |
| `Disabled: unsupported engine/API SHA-256` | Сборка клиента не поддерживается. Приложи строку `Compatibility:` из лога к GitHub issue. |
| `Console: 12 Agn_ commands registered` | Команды зарегистрированы; проверь `Agn_Status` в консоли. |
| `active=1`, но `packets=0` | Нужен другой игрок, говорящий через совместимый Steam Voice. |
| Обрывы, шипение, роботизация | Для сравнения введи `Agn_Enable 0`. В issue приложи `Agn_Status`, хеши и конец лога, не запись чужого голоса. |

`active=1` означает включённый модуль, а не гарантию качества.
Рост `overruns` означает сброс аудио из переполненной очереди.

## Совместимость

Модуль устанавливается **каждому игроку отдельно**. Это не плагин сервера:
установка на сервер не меняет звук у подключившихся игроков.
Steam Legacy и произвольные сборки CS не заявлены как поддерживаемые.

`hw.dll` — один из двух:

```text
17D65A30098152A6A7B94B37D3BF5E86FD627A644E2450087B55616F5A792CED
08B138B9F1B137CEAE15D4BB0751C38D98095AE4C0B50411F72080F047A9960C
```

`steam_api.dll`:

```text
DC8B3B9AFF2A1FE6320FC66DC0A5980D0CDF949606B24FAC9843AB452470C048
```

При неизвестных файлах Voice48 отключается и оставляет штатный звук.
Не заменяй DLL игры чужими файлами и не отключай проверку совместимости.

</details>

В v9 я добавила поддержку обновлённого проверенного `hw.dll` и вывод хешей
в лог. Команды и обработку звука v8 я сохранила. Подробности автотестов —
в `Проверка сборки.txt` внутри архива; они не заменяют проверку речи на сервере.

## Удаление

Закрой CS и убери `Voice48.asi`. Для возврата прежней версии восстанови свой
бэкап. Файлы движка и конфиги игры менять не требуется.
